# Catálogo do jogo (Albion Online 1.32.040)

Dados do próprio jogo (pasta `GameData`, decifrada), organizados por assunto em 13 pastas, com nomes em português. Guardado aqui para não se perder e para ser consultado sempre que for preciso reforçar o entendimento de qualquer parte do jogo (itens, habilidades, monstros, loot, zonas, masmorras, PvP, missões, textos etc.).

- `Catalogo-Albion-1.32.040.zip`: o catálogo completo (68 MB descompactado). Dentro: 13 pastas por assunto (`01-itens` … `13-textos`), tabelas `.csv` fáceis de ler (`itens.csv`, `habilidades.csv`, `monstros.csv`, `monstros_listas_de_loot.csv`…), o `.json` completo de cada arquivo do jogo, `dicionario_de_campos.json` e `GUIA.html`.
- `LEIA-ME.md`: o que há em cada pasta e como usar.
- `INDICE_DE_ARQUIVOS.csv`: um arquivo do jogo por linha, com assunto, tamanho e principais registros (para achar rápido onde fica cada dado sem abrir o zip).

Para usar: `unzip Catalogo-Albion-1.32.040.zip -d catalogo` e procurar pelo `INDICE_DE_ARQUIVOS.csv`.

Versão do jogo: 1.32.040. Quando o jogo atualizar, gerar de novo e substituir o zip.
